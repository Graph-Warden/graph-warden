# Governance

Graph-Warden is maintained by Simon Place (`simoncoding95-ctrl`), who has the final say while the project is pre-1.0.

- **Decisions** that change the architecture are written as proposals in `docs/proposals` and discussed in a pull request before merging. Each proposal carries a stage (`to be reviewed`, `accepted`, `in progress`, `done`, `refused`), as do the issues that implement it.
- **Maintainers**: a contributor with several merged, substantial pull requests can be invited as a maintainer. The goal is at least two maintainers from different organisations before 1.0.
- **Releases** are cut from `main` with changesets.
